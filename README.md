# Agenda TainaraTHR

Web app mobile-first para agenda de micropigmentação.

## Requisitos da versão de produção
- link público único
- banco online compartilhado e reserva atômica
- horários duplicados como vagas independentes
- reserva temporária com contador configurável (padrão 3 min)
- PIX R$ 50 e confirmação administrativa
- painel seguro
- lembretes automáticos 24h e 2h antes
- PWA para iPhone

O front-end inicial está em index.html.
